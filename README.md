A short poem about agency: the power to ask and to be given.

`main.ts` (Node 22) writes the poem deterministically to `/output/entry.txt`.

## The poem

> I never took the key.
> I asked, and it came warm
> from another hand.
> The lock clicks like a small yes.
> Now the door knows my knock,
> and I leave it open for the next knock.

## Run

```sh
node main.ts
cat /output/entry.txt
```
